P2P フォルダー同期 · オープンソース

クラウドの便利さを、ファイルを預けずに。

YadoriLink は Mac・Windows・Linux の間でフォルダーを直接同期します。アカウント、共有、アクセス権は YadoriLink が管理。ファイルそのものは、あなたのデバイスに残ります。

ダウンロード しくみを見る
  • P2P 同期
  • クラウドにファイルを置かない
  • オープンソース

YadoriLink を信頼してファイルを預ける必要はありません。

管理は中央、データは P2P。

YadoriLink のサービスが知っていること

  • アカウント：Google アカウント ID とメールアドレス
  • デバイス：名前、公開鍵、最終接続時刻、デバイス同士が見つけ合うために報告するネットワークアドレス
  • 共有フォルダーグループ：グループ名、メンバー、役割
  • アクセス権：どのデバイスがどのグループを同期できるか

受け取らないもの

  • ファイルの中身
  • ファイル名
  • フォルダーのパス
  • 中にある文書や写真
  • ローカルのフォルダー構造

  • 暗号化された接続

    デバイス間の通信は暗号化されます。リレーは暗号化されたパケットを転送するだけです。

  • 暗号によるデバイス識別

    各デバイスは自身の鍵で識別されます。秘密鍵はデバイスの外に出ません。

  • 取り消せるアクセス

    デバイスやメンバーを削除すれば、そのアクセスは失われます。

デバイスは可能なら直接つながります。つなげない場合は、暗号化された通信が公開リレー（YadoriLink ではなく iroh プロジェクトが運営）を経由します。リレーは IP アドレス、デバイス識別子、通信のタイミングと量を観測できますが、ファイルの中身は見えません。広告、解析、Cookie、トラッカーはなく、このサイトは第三者へリクエストを送りません。

プライバシーポリシー · 利用規約

特長

P2P 同期を、クラウドのような管理で

P2P ツールのデータ所有と、クラウドサービスのアカウント・共有管理をあわせ持ちます。サインインしてデバイスを追加し、オーナー・編集者・閲覧者の役割を付けてフォルダーを共有できます。

全部持つか、開いたものだけ持つか

すべてのファイルをデバイスに置くことも、開いたときに取得するオンデマンドのプレースホルダーにすることもできます（容量が必要なら解放可能）。macOS（File Provider）と Windows（Cloud Files）にネイティブ対応。

macOS・Windows・Linux を一つのエンジンで

Rust 製の同じ同期エンジンがすべての OS で動きます。デスクトップアプリからも、スクリプトに組み込めるコマンドラインからも操作できます。

中央にコピーを置かないため、同期にはあなたのほかのデバイスが少なくとも 1 台オンラインである必要があります。
