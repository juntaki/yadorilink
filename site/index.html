Peer-to-peer folder sync · open source

Cloud convenience, without handing over your files.

YadoriLink syncs folders directly between your Mac, Windows and Linux devices. YadoriLink manages accounts, sharing and permissions; the files themselves stay on your devices.

Download See how it works
  • P2P sync
  • No cloud file storage
  • Open source

You don’t have to trust YadoriLink with your files.

The control plane is centralised. The data plane is peer-to-peer.

What the YadoriLink service knows

  • Account: your Google account ID and email address
  • Devices: name, public key, last-seen time, and the network addresses devices report so they can find each other
  • Shared folder groups: group name, members and roles
  • Access rights: which devices may sync which group

What it never receives

  • File contents
  • File names
  • Folder paths
  • The documents and photos inside
  • Your local folder structure

  • Encrypted connections

    Device-to-device traffic is encrypted. Relays only forward encrypted packets.

  • Cryptographic device identity

    Each device is identified by its own key. Private keys never leave the device.

  • Revocable access

    Remove a device or a member and it loses access.

Devices connect directly when they can. Otherwise, encrypted traffic passes through public relays run by the iroh project, not by YadoriLink. Relays can observe IP addresses, device identifiers, timing and traffic volume, but not file contents. No ads, analytics, cookies or trackers; this website makes no requests to third parties.

Why YadoriLink

Peer-to-peer sync, cloud-style management

The data ownership of a peer-to-peer tool with the account and sharing management of a cloud service. Sign in, add devices and share folders with roles: owner, editor or viewer.

Store everything, or only what you open

Keep every file on a device, or use on-demand placeholders that download when opened and can be evicted to free space. Native on macOS (File Provider) and Windows (Cloud Files).

macOS, Windows and Linux, one engine

The same sync engine, written in Rust, on every platform, driven by a desktop app or a command-line tool you can script.

Because there is no central copy, a sync needs at least one other of your devices to be online.
